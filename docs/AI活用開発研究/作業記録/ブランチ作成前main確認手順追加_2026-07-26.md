## 検証結果

| 確認 | 結果 |
| --- | --- |
| `git status --short` | 空 |
| `git rev-list --left-right --count main...origin/main` | `0 0` |
| Preflight Skill正本と`.agents`コピー | SHA256一致 |
| Markdown lint | 105ファイル、0エラー |

`git rev-list --left-right --count`の出力はPowerShellでタブ区切りになるため、空白を正規化して`0 0`と判定した。検証式の差分を確認した後、正規化した確認コマンドで再実行し成功した。
