## 表示上の保留・不足

- Backend JaCoCoは既存レポートを読み取り、全体Branch 79.71%が基準未達のため「未通過」として表示している。
- `AuthController`のBranch 1/2を未通過分岐として表示している。
- Backend・Oracleケースは既存レビュー記録に合わせて、資格情報エラーによる未実行として表示している。
- `BE-AUTH-010`、`BE-AUTH-012`、`FE-AUTH-011`は、既存レビューの期待結果補足を「不足」として表示している。
- Oracle接続環境の再確認は、既存のログイン機能レビュー記録に従う。

## GPTレビュー対応

| 指摘 | 対応結果 | 判定 |
| --- | --- | --- |
| 1. 設計品質・実行状態・総合判定の分離 | 受入条件へ4状態を追加し、ケース実行状態から総合判定を導出 | 既存観点で対応 |
| 2. AC-006の品質ゲート化 | AC-006を通常の受入条件から除外し、QG-001へ移行 | 標準化候補 |
| 3. 双方向トレーサビリティ | 生成時に相互参照不一致をエラー検出 | 標準化候補 |
| 4. 根本原因集約 | rootCauses定義でブロッカーと影響ケース数を集約 | 標準化候補 |
| 5〜10. 総合判定・証跡・リンク・フィルター・検証・名称 | 実行情報表示、総合判定ルール、画面内遷移、フィルター連動、検証強化、タイトル変更を実装 | 既存観点で対応 |
