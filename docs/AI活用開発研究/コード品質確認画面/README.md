## 命名規則

機能IDと機能名をフォルダ名・ファイル名へ含める。

```text
F-xxx_機能名/
├─ F-xxx_機能名_コード品質確認.html
├─ F-xxx_機能名_表示データ.json
├─ F-xxx_機能名_生成.ps1
└─ README.md
```

HTMLは生成物、JSONは表示用スナップショットである。仕様、受入条件、テストケースの正本は各機能の設計書と作業記録とする。
